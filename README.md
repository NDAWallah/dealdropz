## 🛠️ Development

Install dependencies with `npm install`, then start `netlify dev --port 8889`. Run `npm run check` for server type checks and `npm test` for browser and access-control checks with the development server running. Browser tests require Playwright Chromium (`npx playwright install chromium`).

## 🔐 Store Owner & Admin Setup

Use the **Admin Dashboard** directly inside the website to:
- Replace or delete sample products with actual Kurti/Fashion product images, Reel Codes (`#105`), checked retailer prices, affiliate URLs, and video Reel URLs.
- Edit any website text, hero banners, categories, and the bottom **"Powered by NDA WALLAH"** footer branding.
- Configure official **YouTube, Instagram, Telegram, and WhatsApp** links in the Community tab.
- Track live retailer click analytics across Amazon, Flipkart, and Meesho.
